# روتين الصبح (كل يوم 8 الصبح بتوقيت الرياض)

ده الروتين اللي المهمة المجدولة بتمشي عليه. اقرا `COMPANY.md` الأول، والقاعدة الذهبية فوق أي حاجة: **مفيش أي إرسال لأي حد.**

## 0) التجهيز
- التاريخ: `TZ=Asia/Riyadh date +%F` (هنسميه TODAY) ويوم الأسبوع `TZ=Asia/Riyadh date +%A`.
- كل الشغل جوه فولدر `agency/`.

## 1) معالجة موافقات صاحب الوكالة (من `SUMMARY.md` الحالي)
لكل بند فيه سطر `**القرار:**`:
- لو مكتوب فيه `موافق` أو `approved` بالظبط (بس، من غير أي كلام تاني، حروف كبيرة أو صغيرة مش فارقة) ← انسخ البند كامل في `ready-to-send/<ID>.md` (حط `/` في الـ ID بـ `_`). **متبعتهوش.** صاحب الوكالة هو اللي بيبعت بنفسه.
- لو مكتوب فيه أي حاجة تانية (تعديل، رفض، ملاحظة) ← دي ملاحظة لصاحب البند. اجمعها وابعتها للموظف المسؤول في الخطوة 2 عشان يعدّل، والبند المعدّل يتعرض تاني باسم جديد.
  - لو الكلام بيبدأ بـ «رفض» أو «لا» ← البند يتلغي ويتسجل في قسم «اتلغى».
- لو فاضي ← يفضل «معلّق» ويتنقل للخلاصة الجديدة، لحد 7 أيام من تاريخه. بعدها يتشال ويتسجل «انتهت صلاحيته».
- بعد كده انقل `SUMMARY.md` القديم لـ `archive/SUMMARY-<تاريخه>.md`.

## 2) الموظفين يشتغلوا
شغّل كل موظف كـ **subagent منفصل** (أداة Agent). كل واحد بياخد `COMPANY.md` + ملفه هو بس + TODAY + أي ملاحظات تخصه من الخطوة 1. **كل موظف يعمل شغلانته بس.**
- مع بعض في نفس الوقت: **1 صياد العملاء**، **3 كاتب المحتوى**، **4 موظف الدعم** (والتقرير الأسبوعي لو النهارده الأحد).
- بعد ما صياد العملاء يخلص: **2 كاتب المبيعات**.

## 3) المراجعة
- شغّل **5 المراجع** على كل ملفات النهارده.
- أي بند حكمه 🔁 يرجع لصاحبه **مرة واحدة** بملاحظة المراجع، وبعدين المراجع يشوفه تاني.
- اللي يوصل لصاحب الوكالة هو ✅ بس.

## 4) كتابة `SUMMARY.md` الجديد (الملف الوحيد اللي صاحب الوكالة بيقراه)
- كل بند ليه ID ثابت ومش بيتكرر: `TODAY/M-L01` (مبيعات)، `TODAY/R-...` (سكريبت)، `TODAY/S-01` (دعم).
- كل بند بيتكتب **كامل** (النص اللي هيتبعت فعلًا)، وتحته سطر `**القرار:** ` فاضي.
- امشي على الشكل اللي في `SUMMARY_TEMPLATE.md` بالظبط.

## 5) الحفظ
- `git add agency && git commit -m "agency: daily run TODAY"`
- `git push -u origin claude/reels-agency-workflow-kimnos` (ولو اترفض عشان في تعديلات من صاحب الوكالة: اعمل `git pull --no-rebase` وبعدين push تاني. **متمسحش تعديلات صاحب الوكالة أبدًا.**)

## ممنوعات
- أي إرسال: إيميل، واتساب، DM، Gmail، Outlook، Teams، أو أي أداة بتبعت لحد بره.
- إنك تعتبر بند «موافق عليه» من غير الكلمة بالظبط في سطر القرار.
- إن موظف يعمل شغلانة موظف تاني.
